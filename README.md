## Python Testing Tutorial

This repository includes a simple example of how to write and test Python code.

### 1. The Code (`calculator.py`)
This file contains a simple function `add(a, b)` that returns the sum of two numbers.

### 2. The Tests (`test_calculator.py`)
This file uses Python's built-in `unittest` framework to verify that the `add` function works correctly. It checks that `add(2, 3)` is `5` and `add(-1, 1)` is `0`.

### Running the Tests
You can run the tests using the following command in your terminal:
```bash
python -m unittest test_calculator.py
```
If everything is correct, it will output an `OK` message.
